Home
Accueil (/) : Le point d'entrée avec les accès rapides aux différentes sections.

Gestion des Clients
Inscription (/register) : Formulaire pour créer un nouveau compte client.

Liste des comptes (/list-account) : Vue d'ensemble de tous les clients enregistrés.

Gestion de la Flotte
Ajouter un bateau (/boat/new) : Formulaire pour lier un nouveau bateau à un client existant.

Tous les bateaux (/liste-des-bateaux) : La liste complète de la flotte.

Flotte de Luxe (/liste-des-bateaux-luxury) : Un accès rapide aux navires d'exception (valeur > 1M€).

Bateaux par client (/account/{firstname}/boats) : Permet de voir tous les bateaux appartenant à un propriétaire spécifique.

Assurance & Contrats
Calcul de prime (/insurance/{id}) : Affiche le détail du calcul de l'assurance pour un bateau spécifique.

Télécharger le contrat (/insurance/download) : Génère et télécharge instantanément le contrat d'assurance au format PDF.
